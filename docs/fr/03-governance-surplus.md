# 3. Gouvernance et surplus

Le dépôt inclut des contrats DAO, ANGLE, veANGLE, gauges et distribution de surplus. Ces briques traduisent les décisions de gouvernance en paramètres, émissions ou allocations. Les permissions et les délais associés sont donc aussi importants que les fonctions économiques.

Les stratégies produisent ou redistribuent du rendement selon des contrats spécialisés. Le Core Module peut référencer ces stratégies, mais le README précise que les versions à jour vivent dans un autre dépôt.

Une lecture sérieuse doit suivre les adresses, les rôles et les appels inter-modules avant de conclure sur la sécurité d’un déploiement.
