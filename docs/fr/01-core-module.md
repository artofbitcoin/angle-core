# 1. Le Core Module

Angle est un protocole de stablecoin surcollatéralisé. Le dépôt angle-core rassemble les contrats du Core Module ainsi que des contrats de gouvernance et de staking. Le module organise la création, la gestion du collatéral, la stabilité et la distribution des excédents autour de contrats spécialisés.

Le README renvoie aux autres dépôts pour l’emprunt et les stratégies : le périmètre doit donc être lu comme un composant, pas comme la totalité du protocole.
