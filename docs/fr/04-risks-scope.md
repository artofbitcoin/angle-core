# 4. Risques et périmètre

Les risques principaux sont la solvabilité du collatéral, les oracles, les permissions de gouvernance, les changements inter-modules et les stratégies de rendement. Le dépôt publie des audits et un programme de bug bounty, mais ces éléments ne remplacent pas une vérification indépendante de chaque déploiement.

Ce parcours couvre uniquement les contrats et indications lisibles dans angle-core. Il ne constitue ni un audit ni une recommandation. Aucune installation, compilation, exécution ou validation de test n’a été réalisée.

Les lecteurs souhaitant aller plus loin doivent comparer les dépôts angle-borrow et angle-strategies avec les versions réellement déployées.
